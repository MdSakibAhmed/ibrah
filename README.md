# ইবরা (Ibrah) — প্রজ্ঞা ও আত্মশুদ্ধির ডিজিটাল ডায়েরি

**ইবরা** হলো একটি আধুনিক, শান্ত ও সুরক্ষিত মোবাইল অ্যাপ যা দৈনন্দিন জীবনের বিভিন্ন ঘটনা, দ্বীনি আলোচনা, পারিবারিক বা দাম্পত্য কথোপকথন থেকে প্রাপ্ত মূল্যবান শিক্ষা ও উপলব্ধি (হিকমাহ) ধরে রাখতে এবং পরবর্তীতে রিভিজিট করতে সাহায্য করে।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Core Features)

1. **ভয়েস-ফার্স্ট ক্যাপচার (Zero-Friction Voice Capture):**
   - স্ক্রিনের বড় মাইক বাটনে ট্যাপ করে কথা বলে তাৎক্ষণিক রেকর্ড করুন।
   - লাইভ অডিও ওয়েভফর্ম ও টাইমার ডিসপ্লে।
   - চাইলে লিখেও নোট ও উপলব্ধি সেভ করার সুবিধা।

2. **এআই দ্বারা স্বয়ংক্রিয় প্রজ্ঞা নিষ্কাশন (Speech-to-Wisdom AI):**
   - Google Gemini Multimodal API এর মাধ্যমে বাংলা ও ইসলামি পরিভাষা সমৃদ্ধ অডিও সরাসরি বিশ্লেষণ।
   - অডিও থেকে স্বয়ংক্রিয়ভাবে ৪টি প্রধান অংশে সাজিয়ে দেওয়া:
     - **শিরোনাম (Title):** অর্থপূর্ণ ও আকর্ষণীয় নাম।
     - **মূল উপলব্ধি বা শিক্ষা (Hikmah/Learning):** ঘটনা থেকে কী শিখলাম।
     - **ভবিষ্যতের অঙ্গীকার (Action Item):** নিজেকে কীভাবে শুধরাব বা ভবিষ্যতে কী করব।
     - **প্রেক্ষাপট (Story) ও সারসংক্ষেপ (Summary):** গুছিয়ে লেখা সম্পূর্ণ ঘটনা।
     - **স্মার্ট ট্যাগ (Tags):** বিষয়ভিত্তিক ট্যাগ (যেমন: `#সবর`, `#দাম্পত্য`, `#নম্রতা`)।

3. **অতীতের শিক্ষা রিভিজিট (Daily Wisdom / Flashback):**
   - হোম স্ক্রিনের শীর্ষে প্রতিদিন অতীতের কোনো না কোনো শিক্ষা ভেসে ওঠে।
   - রিলোড বাটনে ট্যাপ করে র্যান্ডমলি অতীতের অন্যান্য হিকমাহ দেখা যায়।
   - স্পেসড রিপিটেশনের মাধ্যমে নিজের আত্মউন্নয়ন ধরে রাখা সহজ হয়।

4. **প্রজ্ঞা ও শিক্ষা হাব (Learnings Hub):**
   - শুধু শিক্ষা ও অ্যাকশন আইটেমগুলোর একটি ডেডিকেটেড ভিউ।
   - ট্যাগভিত্তিক ফিল্টারিং (যেমন: কেবল `#দাম্পত্য` বা `#সবর` সম্পর্কিত শিক্ষাগুলো একনজরে পড়া)।

5. **গুগল ড্রাইভে নিরাপদ ব্যাকআপ ও রিস্টোর (Google Drive Backup & Restore):**
   - এক ক্লিকে সমস্ত নোট, শিক্ষা ও মেটাডাটা ব্যাকআপ তৈরি করে সরাসরি গুগল ড্রাইভে সেভ করার সুবিধা।
   - পূর্বে সেভ করা ব্যাকআপ ফাইল নির্বাচন করে তাৎক্ষণিক সম্পূর্ণ ডেটা রিস্টোর।

6. **উচ্চমাত্রার নিরাপত্তা ও গোপনীয়তা (Hardware-Backed Security):**
   - কোনো সাধারণ বা অরক্ষিত টেক্সটে কোনো পাসওয়ার্ড বা এপিআই কী রাখা হয় না।
   - `expo-secure-store` এর মাধ্যমে ডিভাইসের হার্ডওয়্যার কিচেইন (iOS Keychain) ও কিস্টোরে (Android KeyStore) এপিআই কী সুরক্ষিত থাকে।
   - আপনার সমস্ত চিন্তা ও ডায়েরি ১০০% অফলাইনে আপনার নিজস্ব ডিভাইসে `SQLite` ডাটাবেজে সংরক্ষিত থাকে। কোনো থার্ড-পার্টি ট্র্যাকিং নেই।

## 🚀 কীভাবে অ্যাপটি চালাবেন (How to Run)

প্রজেক্টের রুটে গিয়ে নিচের কমান্ডগুলো দিন:

```bash
# ডিপেনডেন্সি নিশ্চিতকরণ
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npx expo start
```

- আপনার মোবাইলে **Expo Go** অ্যাপ (Play Store / App Store থেকে ডাউনলোডযোগ্য) দিয়ে কিউআর (QR) কোডটি স্ক্যান করলেই অ্যাপটি সরাসরি আপনার ফোনে চালু হয়ে যাবে।
- অথবা অ্যান্ড্রয়েড এমুলেটরে চালাতে `a` চাপুন, কিংবা ব্রাউজারে দেখতে `w` চাপুন।

## 🔑 AI ফিচার ব্যবহারের জন্য (Gemini API Key সেটআপ)

1. অ্যাপটি চালু করে উপরের ডানপাশের **সেটিংস** আইকনে যান।
2. [Google AI Studio](https://aistudio.google.com/) থেকে সম্পূর্ণ বিনামূল্যে একটি API Key সংগ্রহ করুন।
3. API Key বক্সে পেস্ট করে **"সংরক্ষণ করুন"** বাটনে চাপ দিন।
4. এটি আপনার ডিভাইসের হার্ডওয়্যার এনক্রিপশনে সুরক্ষিত হয়ে যাবে।

*(দ্রষ্টব্য: ইন্টারনেট না থাকলে বা এপিআই কী না দিলেও আপনার ভয়েস রেকর্ড কখনোই হারিয়ে যাবে না—অডিও ফাইল সেভ থাকবে এবং পরবর্তীতে ইন্টারনেট বা কী দিয়েও এআই ট্রান্সক্রাইব করতে পারবেন।)*

## 📁 আর্কিটেকচার ওভারভিউ (Project Architecture)

```
src/
├── app/                      # Expo Router পেজ ও নেভিগেশন
│   ├── _layout.tsx           # রুট স্ট্যাক নেভিগেটর
│   ├── index.tsx             # হোম স্ক্রিন (টাইমলাইন, ফ্ল্যাশব্যাক ও সার্চ)
│   ├── record.tsx            # ভয়েস রেকর্ডিং ও এআই প্রসেসিং স্ক্রিন
│   ├── learnings.tsx         # সকল শিক্ষা ও হিকমাহ হাব
│   ├── settings.tsx          # গুগল ড্রাইভ ব্যাকআপ ও এপিআই কনফিগারেশন
│   └── reflection/
│       └── [id].tsx          # বিস্তারিত স্টোরি, অডিও প্লেয়ার ও এডিট
├── components/               # রিইউজেবল ইউআই কম্পোনেন্ট
│   ├── AudioPlayerCard.tsx   # অডিও প্লেয়ার (Play/Pause/Seek)
│   ├── DailyWisdomCard.tsx   # অতীতের ফ্ল্যাশব্যাক কার্ড
│   ├── ReflectionCard.tsx    # টাইমলাইন আইটেম কার্ড
│   ├── WaveformIndicator.tsx # অ্যানিমেটেড অডিও পালস
│   ├── FilterPill.tsx        # ক্যাটাগরি ফিল্টার
│   └── Header.tsx            # হেডার কম্পোনেন্ট
├── constants/                # থিম ও ক্যাটাগরি কনস্ট্যান্ট
│   ├── theme.ts              # শান্ত এমারেল্ড ও গোল্ড কালার প্যালেট
│   └── categories.ts         # দ্বীন, দাম্পত্য, আত্মশুদ্ধি ইত্যাদি ক্যাটাগরি
├── services/                 # কোর লজিক ও ডেটা সার্ভিস
│   ├── database.ts           # SQLite সুরক্ষিত লোকাল স্টোরেজ (CRUD)
│   ├── ai.ts                 # Google Gemini Multimodal এআই সার্ভিস
│   ├── backupService.ts      # গুগল ড্রাইভ এক্সপোর্ট ও ইমপোর্ট সার্ভিস
│   └── securityService.ts    # SecureStore ও স্যানিটাইজেশন সার্ভিস
└── types/
    └── reflection.ts         # টাইপস্ক্রিপ্ট ইন্টারফেস
```
